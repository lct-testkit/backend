# Шаблоны документов по инцидентам (B6-12)

Три шаблона, из которых система сама формирует PDF, лежат не здесь, а в
[`app/assets/templates/security/`](../../../app/assets/templates/security/):

- `rkn-notice-24h.md.j2` — уведомление Роскомнадзора в течение 24 часов;
- `rkn-notice-72h.md.j2` — уведомление об итогах расследования (72 часа);
- `subjects-notice.md.j2` — уведомление субъектов персональных данных.

Причина переноса: образ контейнера копирует только `app/`, `migrations/` и `alembic.ini`,
каталог `docs/` в него не попадает — шаблоны, оставшиеся тут, код в контейнере не находил.
Все три — черновики (`status: draft`), требуют утверждения юристом оператора.

Здесь остаётся `investigation-report.md.j2` — внутренний шаблон отчёта о расследовании для
ручного заполнения; системой не рендерится.
