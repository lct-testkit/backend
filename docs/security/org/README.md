# Пакет организационных документов (B6-14)

152-ФЗ ст. 18.1 требует от оператора организационные меры — не только код. На проверке
(в том числе Роскомнадзором) первыми спрашивают бумаги, а не репозиторий. Этот каталог даёт
шаблоны пяти документов, которые ссылаются на реальный код и на
[матрицу мер ФСТЭК/152-ФЗ](../measures-matrix.md) (B6-1).

**Все документы в этом каталоге — черновики (`status: draft`).** Формулировки нормативных
актов приведены по памяти авторов спринта и не заменяют консультацию юриста. Перед
использованием на проверке каждый документ должен получить `status: approved` от юриста
оператора и реального ответственного (поля `{{...}}` — заполняются при утверждении).

## Как читать перечень ПДн (02)

Строится по коду, а не по памяти: `backend/tests/test_pdn_inventory.py` разбирает
`app.db.models` и требует, чтобы каждая колонка, похожая на ПДн по имени, была упомянута в
перечне либо явно исключена с причиной. Новая колонка в модели без строки в перечне — красный
тест с именем колонки в сообщении.

## Срок хранения

Сроки в [01-pdn-policy.md](01-pdn-policy.md) и [02-pdn-inventory.md](02-pdn-inventory.md) не
вписаны числами вручную — они взяты из `app/core/config.py` (B6-6, `retention_*`) и из
`signature_otp_max_sends`/`SIGNATURE_OTP_MAX_SENDS` (B7). Если число в коде изменится, документ
должен быть обновлён тем же PR (тот же принцип, что у матрицы мер B6-1).
